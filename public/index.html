HOW IT WORKS

Built on clean data structures

Runs directly on a C++ backend with no database bloat.

STRUCTURE 01

Hash Map (Chaining)

Finds rooms in constant time using separate chaining, no matter how many venues exist.

Time: O(1) avg
STRUCTURE 02

Min-Heap Waitlist

Orders requests fairly by priority role and timestamp, advancing automatically when a room opens.

Time: O(log N)
STRUCTURE 03

Action Stack

Keeps track of every booking and cancellation so you can step back whenever you make a mistake.

Time: O(1)
STRUCTURE 04

Campus Graph Router

Computes the quickest route and estimated walking minutes across all connected campus blocks.

Time: O(E log V)
